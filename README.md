### **Vì sao xài filetype:pdf lại lẹ hơn?**

* **Khỏi mất công click linh tinh:** Gõ "tải sách" toàn dính web rác, bắt đợi đếm ngược, ép nạp thẻ cào hoặc bấm nhầm link quảng cáo bẩn. Dùng filetype:pdf là nó móc thẳng file tài liệu gốc ra cho tải luôn.
* **An toàn máy tính:** Né sạch mấy con web giả dạng file PDF nhưng thực chất nhét mã độc hoặc file .exe. Lấy trực tiếp trên ptit.edu.vn là chuẩn bài, ko sợ dính virus.
* **Đúng mục đích:** Vào phát thấy đúng file giáo trình của trường biên soạn để ôn thi luôn, ko bị loãng kết quả.
